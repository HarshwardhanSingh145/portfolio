# Harshwardhan Singh (Vardhan.) Portfolio

Interactive Portfolio for **Harshwardhan Singh** (**Vardhan.**), AI/ML Engineer & Web Designer.

## 🚀 Quick Start

To run the portfolio locally:

```bash
npm start
```
Or:
```bash
node server.js
```

Then open [http://localhost:3000/](http://localhost:3000/) in your browser.

## 📁 Project Structure

- `public/`: Static web application files (HTML, JS, CSS, media assets, fonts).
  - `index.html`: Hero Section & Landing page.
  - `design.html`: Interactive Design & Engineering Wing.
  - `contact.html`: Contact & booking form.
- `server.js`: Node.js HTTP server.
- `package.json`: Project scripts & metadata.
